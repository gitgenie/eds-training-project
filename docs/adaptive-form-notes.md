# Adaptive Form setup notes

## Status

The Adaptive Form requires an Adobe organization sandbox and cannot be created
or tested from this repository alone.

## Setup checklist

1. Create or open an AEM Sites project using the Edge Delivery Services template.
2. Enable the Universal Editor integration for the site.
3. Add an Adaptive Form to the page using the Adaptive Form Editor.
4. Configure the form's submit action and validation rules in the sandbox.
5. Preview and publish the page, then verify the form submission in the target
   environment.

The form configuration and submitted data remain in the AEM sandbox; this
repository only stores these notes.
